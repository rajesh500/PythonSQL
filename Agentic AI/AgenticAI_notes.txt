## How LLM "Memory" Actually Works

• Stateless by Design: Once an LLM finishes answering your message, it retains zero memory of the interaction. From the AI's perspective, every new prompt is a blank slate (like a Groundhog Day scenario).

• The Illusion of Memory (Context Window): When you chat with an AI, the app or website you are using (like ChatGPT or Claude) saves your chat history in a database. Every time you send a new message, the app resends the entire conversation history (plus your new message) back to the LLM.

• The Context Window Limit: LLMs have a strict limit on how much text they can read at once, known as a context window (measured in tokens, which are chunks of words). If your conversation gets too long and exceeds this limit, the app has to drop older messages or summarize them. That is why the AI "forgets" things you talked about earlier in a long chat.

LLM may not respond properly

2. Sending only the latest Question
We are not provding previous context in the request. LLM
cannot remember your previous information as it is
stateless(Gajani)

3. We can send unlimited history
 It should be based on the following:
 context window limits
 token usage
 cost
 latency

4. Confusing List object as Permanent Memory

Most Important Points to Remember
Point 1: A prompt is the input/instruction given to an AI model.
Point 2: A static prompt is fixed.
Point 3: A dynamic prompt contains values that can change.
Point 4: {topic} is an example of an input variable/placeholder.
Point 5: PromptTemplate helps us create reusable dynamic text
prompts.
Point 6: PromptTemplate does not generate the AI answer. It
will generate final prompt.
For this we have to use pt.invoke()
Point 7: The generated prompt is passed to the model. For this
we have to use llm.invoke()
Point 8: For a very simple requirement, a normal Python f-string
may be enough. Use LangChain abstractions when they help
the application structure.
Template + Data = Final Prompt
Final Prompt + LLM = AI Response
Multiple variables:
---------------------
A prompt template can contain more than one placeholder.
Each placeholder can receive a different value at runtime.
eg:
Explain {Topic}
Explain Python in Telugu
Explain {topic} in {language}
Explain Python in Telugu for Beginner level in Simple Style
Explain {topic} in {language} for {level} level in {style} Style

import os
from langchain_openai import ChatOpenAI
from langchain_core.prompts import PromptTemplate
# Create model
llm = ChatOpenAI(
 model="gpt-4o-mini",
 api_key=os.getenv("OPENAI_API_KEY")
)
# Create reusable template
template = PromptTemplate.from_template(
 """
 Teach me {topic}.
 Student Level: {level}
 Language: {language}
 Explanation Style: {style}
 Requirements:
 1. Explain in easy language.
 2. Give 5 important points.
 3. Give 2 real-life examples.
 4. Mention one common mistake.
 5. End with a one-line conclusion.
 """
)
# Take user inputs
topic = input("Enter topic: ")
level = input("Enter your level: ")
language = input("Enter language: ")
style = input("Enter explanation style: ")
# Generate prompt
prompt = template.invoke(
 {
 "topic": topic,
 "level": level,
 "language": language,
 "style": style
 }
)
# Inspect generated prompt
print("\n========== GENERATED PROMPT ==========")
print(prompt.to_string())
# Send to model
response = llm.invoke(prompt)
# Display response
print("\n========== AI RESPONSE ==========")
print(response.content)
