-----------------------------

Understanding Messages and Message Types:
-----------------------------------------
Message: It is a structured unit of communication in a
conversation with a chat model.
3 types of Messages:
1. SystemMessage--->Instructions/context that guide the
model. It decides behaviour of the Model.
2. HumanMessage--->Message from human/user
3. AIMessage--->Response from Model

## How LLM "Memory" Actually Works

• Stateless by Design: Once an LLM finishes answering your message, it retains zero memory of the interaction. From the AI's perspective, every new prompt is a blank slate (like a Groundhog Day scenario).

• The Illusion of Memory (Context Window): When you chat with an AI, the app or website you are using (like ChatGPT or Claude) saves your chat history in a database. Every time you send a new message, the app resends the entire conversation history (plus your new message) back to the LLM.

• The Context Window Limit: LLMs have a strict limit on how much text they can read at once, known as a context window (measured in tokens, which are chunks of words). If your conversation gets too long and exceeds this limit, the app has to drop older messages or summarize them. That is why the AI "forgets" things you talked about earlier in a long chat.

import os
from langchain_core.messages import SystemMessage,
HumanMessage, AIMessage
from langchain_openai import ChatOpenAI
OPENAI_API_KEY = os.getenv("OPENAI_API_KEY") #function
llm = ChatOpenAI(model="gpt-4o",api_key=OPENAI_API_KEY)
msgs = []
sys_msg = SystemMessage( content = "You are a helpful
assistant and answer in simple english and in concise way")
msgs.append(sys_msg)
while True:
question = input("You: ")
if question.lower() == "exit":
break
msgs.append(HumanMessage(content = question))
print('The Number of messages sending:', len(msgs))
ai_message = llm.invoke(msgs)
msgs.append(ai_message)
print('AI:', ai_message.content)

Context: It is information available to the model that helps it
understand current request.
Context Window: It is the maximum amount of information an
LLM can consider at one time while generating response.



Context Window size is measured in terms of tokens.
| Model | Context window |
| ----------------- | ----------------------: |
| **GPT-5.6 Sol** | **1.05 million tokens** |
| **GPT-5.6 Terra** | **1.05 million tokens** |
| **GPT-5.6 Luna** | **1.05 million tokens** |
| GPT-5.4 | 1.05 million tokens |
| GPT-5.4 Mini | 400,000 tokens |
| GPT-5.4 Nano | 400,000 tokens |
| GPT-4.1 | 1,047,576 tokens (~1M) |
| GPT-4o | 128,000 tokens |
